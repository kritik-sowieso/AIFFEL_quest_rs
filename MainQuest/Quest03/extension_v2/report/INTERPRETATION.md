# 추가 실험 해석 · 논문 반영안

- 실행 완료: D/B/C 각각 10회 학습 · 5·10회차 고정 평가
- 실제 실행 시간: 약 39.3분 · 90분 상한 이내
- 평가 출력: 18개 파일 · 총 372개 생성 · 누락 없이 검수
- 기반 모델 A: 동일 모델 버전·지시·자료의 기존 출력 재사용
- 게시·데모 모델 변경: 없음

## 핵심 결론

- 학습량 확대: 세 학습 조건 모두 5→10회차에서 문자 목록 F1·문자/좌표 F1 개선
- 제안 방법 C: B보다 10회차 문자/좌표 F1이 6.25%p 높음
- 문자 보존: C의 문자 목록 F1은 B보다 2.06%p 낮음
- 완전한 문구 생성: B와 C 모두 테스트 정답 0/25 · 좌표 보조학습의 완전 정답률 개선 미확인
- 변환 전용 D: 테스트 1/25 정답 · 정답 문구 `다리`
- 종합: 미세 조정과 학습량 확대에 따른 부분 점수 개선 관찰 · 좌표 보조학습의 기여는 제한적·혼합적

## 구성요소 비교

| 비교 | 실제 관찰 | 주장 가능한 범위 |
|---|---|---|
| D 대 A | 문자 목록 F1 0.16→53.30% · 문자/좌표 F1 0.16→26.36% · 정답 0→1/25 | 과업 미세 조정 후 요청 형식·부분 일치 개선 |
| B 대 D | 문자 목록 F1 53.30→55.98% · 문자/좌표 F1 26.36→22.16% · 정답 1→0/25 | 자모 목록 보조과제의 효과는 지표별로 다름 · 일관된 개선 아님 |
| C 대 B | 문자 목록 F1 55.98→53.91% · 문자/좌표 F1 22.16→28.41% · 정답 0→0/25 | 위치를 포함한 부분 점수의 유리한 관찰 · 완전 생성 향상 입증 아님 |

- C 대 B의 문구별 문자/좌표 F1: C 우세 11개 · 동점 7개 · B 우세 7개
- 위 건수: 같은 문구끼리 짝지은 기술 통계 · 통계적 유의성 결과 아님
- A: 고정 영문 지시에서 추가학습 전의 작은 Qwen 모델 · 강력한 상용 LLM 전체의 성능으로 일반화 금지

## 5회차에서 10회차로 늘린 효과

| 조건 | 문자 목록 F1 | 문자/좌표 F1 | 완전 정답 |
|---|---:|---:|---:|
| D | 34.89→53.30% | 16.23→26.36% | 0→1/25 |
| B | 40.69→55.98% | 16.87→22.16% | 0→0/25 |
| C | 52.57→53.91% | 20.00→28.41% | 0→0/25 |

- 10회차에서는 세 조건 모두 테스트 생성 토큰 상한 도달 0/25
- 이전 5회차 상한 도달: D 2/25 · B 1/25 · C 0/25
- 불필요한 반복 감소와 부분 문자 일치 개선을 완전한 변환 성공과 구분
- 최초 실험의 선택 모델은 1회차 · 이번 표의 5회차는 새 실행에서 고정 평가한 5회차

## 학습 자료에서도 생성이 충분히 되는가?

- 고정 학습 표본 12개 정답: D 1/12 · B 0/12 · C 1/12
- D/C가 맞힌 학습 문구: `미소`
- 해석: 새로운 문구의 일반화 문제만으로 모든 실패를 설명하기 어려움
- 가능성: 적합 부족·생성 중 누적 오류·모델 표현 능력 등 · 현재 실험으로 원인 확정 불가
- 주의: 학습 표본은 198개 전체가 아니라 사전 고정 12개 · 전체 학습 정확도로 표현 금지
- 검증 정답: D 0/25 · B 0/25 · C 1/25 (`하늘`)
- 테스트와 검증 결과의 차이: C의 검증 1개 성공을 테스트 개선으로 대체하지 않음

- 관찰: C의 이득이 모든 구조에서 고르게 나타나지 않음
- 한계: 집단 간 길이·받침·단어 특성이 겹침 · 독립적인 원인 효과로 해석 금지
- 5음절 이상 문구 4개와 단어 공백 포함 문구 4개는 같은 표본 · 별개의 재현 증거로 세지 않음

## 원시 출력 예시

- 입력 `다리` · D 10회차 출력 `ㄷㅏ ㄹㅣ` · 정답과 일치
- 입력 `기린` · 세 조건의 출력이 모두 같음
- 정답: `ㄱㅣ ㄹㅣ\n   ㄴ`
- 실제 출력: `ㄱ ㄹㅣ\nㅜ ㄴ`
- 관찰: 첫 모음 ㅣ가 ㅜ로 바뀌고 위치도 달라짐 · 단순 공백 오류만이 아님
- 예시의 역할: 오류 형태 설명 · 전체 성능은 모든 25개로 집계

## 재현성·계산량

- 기존 실행 대비 B/C 5회차 검증 원문: 각각 25/25 일치
- 앞 5회차 손실: 작은 수치 차이 존재 · B 최대 약 0.000025 · C 최대 약 0.0000014
- 어댑터 파일: 바이트 단위로 동일하지 않음 · 비트 단위 학습 재현을 주장하지 않음
- 이번 조건별 가중치 갱신: 모두 250회
- 학습 루프 시간: D 약 5.8분 · B 약 11.5분 · C 약 12.9분 · 모델 로딩·평가 제외
- 회차당 정답 토큰: D 2,749 · B 5,457 · C 11,021 · 입력 지시 토큰은 이 수치에 미포함
- 손실 가중치: D 변환 1.0 · B/C 변환 0.5 + 보조 0.5
- 해석: 같은 계산량에서 좌표 정보만 추가한 완전한 통제 실험은 아님

## 논문에 쓸 수 있는 결론

- 저자원 한글 자모 배치 생성에서 추가 학습은 형식 준수와 부분적인 문자·위치 일치를 개선
- 좌표를 포함한 보조학습은 자모 목록 보조학습보다 높은 위치 F1을 보였으나 완전 정답률 개선은 미확인
- 전체 문구를 안정적으로 변환하는 모델 구현에는 추가 검증 필요
- OCR 효과·한국어 의미 이해 전반의 향상·상용 LLM 대비 우월성 주장 불가
- 단일 시드·작은 표본·기존 테스트 재사용의 탐색적 결과로 보고

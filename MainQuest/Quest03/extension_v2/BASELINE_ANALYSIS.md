## 지표의 의미

- 완전 배치 정답: 문자·공백·줄바꿈 전체 일치 · 기존 채점 규칙 유지
- 문자 목록 F1: 위치와 순서를 제외하고 정답 문자를 수량까지 보존한 정도 · 전체 표본을 합친 미시 평균(micro average)
- 문자·좌표 F1: `(문자, x, y)`가 함께 맞는 정도 · 빈칸 제외 · 오답 문자도 분모에 포함
- 추가 진단: 공백 제외 문자 오류율(CER), 누락·추가 문자, 완성형 한글 포함, 토큰 상한 도달
- CER: 행 순서대로 읽은 공백 제외 문자열의 편집 거리 / 정답 문자 수 · 과다 반복 시 100% 초과 가능
- 해석 주의: 문자 목록 F1은 의미 이해나 읽기 정확도가 아님 · 좌표 F1은 자모를 음절에 대응시킨 정확도가 아님
- 분할 분석: 음절 수·받침 유무·가로 모음 유무·단어 공백 유무 · 소집단 크기 표기 · 인과 해석 금지

## 관찰

- A: 23/25에서 완성형 한글 출력 · 8/25에서 생성 토큰 상한 도달
- A: 요청한 자모 출력 형식을 따르지 못하는 현상과 반복 생성 확인
- A 예시 `여행`: 자모 변환 대신 한국어 설명 생성
- A 예시 `달빛`: `아일리언어` 반복
- 완성형 한글이 없는 나머지 2개: `버스` → 빈 표 모양, `기억` → `记忆` · 정상 자모 변환 아님
- B/C: 완성형 한글 포함 0/25 · 자모 출력 형식으로 이동했지만 모든 정답 문자를 보존한 사례 0/25
- 정답 문자 총 165개 중 목록 일치 수: A 2개 · B 58개 · C 59개
- 문자·좌표가 함께 맞은 수: A 2개 · B 15개 · C 17개
- 불필요하게 추가한 문자 수: A 2,292개 · B 591개 · C 842개
- C는 일부 일치 수가 B보다 많지만 불필요한 출력도 많음 · 정밀도와 재현율을 함께 반영한 F1으로 구분
- 해석: 기본 모델은 형식 준수부터 실패 · 미세 조정 모델은 자모 선택·배치 모두 실패
- 결론 제한: 위치만 고치면 해결된다고 단정 불가 · 한국어 의미 이해 능력 전반의 평가 아님
- 좌표 보조학습: 기존 결과에서 B보다 좋은 효과 미확인
- 적용 범위: Qwen2.5-0.5B-Instruct의 고정 영문 지시·탐욕적 생성 조건 · Qwen 전체 모델군의 한계로 일반화 금지
- 원래 동기인 ChatGPT 웹 관찰: 연구 문제를 제기한 사례 · 이번 Qwen 통제 실험의 정량 비교군 아님
- 미검증 요소: 한국어 지시, 예시 제공, 다른 생성 방식 · 이번 승인 실험에는 추가하지 않음

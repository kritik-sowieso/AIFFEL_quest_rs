# 추가 실험을 읽는 순서

- 목적: 처음 실험에서 확인하지 못한 생성 성능을 학습량·구성요소별로 다시 분석
- 현재 원칙: 성공 여부와 관계없이 고정한 조건으로 끝까지 평가

## 1. 기본 모델부터 확인

- [기본 모델 상세 분석](BASELINE_ANALYSIS.md)
- A: 추가학습 전 Qwen2.5-0.5B-Instruct
- 관찰: 정답 0/25 · 완성형 한글 출력 23/25 · 길이 상한 도달 8/25
- 의미: 자모 배치 이전에 요청한 출력 형식을 따르는 문제 존재
- 해석 범위: 이번 모델 크기·고정 지시·생성 설정에서의 결과

## 2. 구성요소 제거 실험 이해

- 구성요소 제거 실험(ablation study): 제안 방법의 구성요소를 빼면서 결과가 어떻게 달라지는지 비교
- D: 변환만 학습 → 과업 미세 조정 자체의 효과 확인
- B: 변환 + 자모 목록 → 자모를 명시적으로 예측하는 보조 과제의 효과 확인
- C: 변환 + 자모·좌표 → 좌표까지 예측하는 보조 과제의 효과 확인
- C 대 B: 주 비교 · 좌표를 추가한 보조 과제의 기여
- B 대 D: 보조 비교 · 자모 목록 과제의 기여
- D 대 A: 보조 비교 · 변환 과업 학습의 기여
- 통제 한계: 과제 수·출력 길이·손실 가중치가 다름 · 같은 계산 시간의 비교 아님

## 3. 5회차와 10회차 구분

- epoch: 학습 자료 전체를 한 번 보는 회차
- 기존 실행: 5회까지 학습 · 검증 동점 규칙으로 1회차 선택
- 추가 실행: 동일 기반 모델에서 처음부터 10회 학습 · 같은 실행 안의 5·10회차 비교
- 이유: 이전 어댑터 파일만으로 옵티마이저 상태까지 완전히 복원 불가
- 고정 기준: 주 비교 10회차 · 부 비교 5회차 · 결과를 본 뒤 유리한 회차로 변경 금지

## 4. 학습 손실과 생성 정답률 구분

- 학습 손실(loss): 정답 앞부분을 제공했을 때 다음 토큰을 예측하는 오차
- 자유 생성: 모델이 자신의 이전 출력을 이어받아 끝까지 생성
- 차이: 처음에 틀린 토큰을 생성하면 이후 출력에도 오류가 이어질 수 있음
- 따라서 손실 하락만으로 변환 성공 주장 금지
- 별도 진단: 학습 표본 12개를 고정하여 자유 생성 결과 확인
- 학습 표본 결과: 학습 내용 적합 여부 관찰용 · 새로운 입력에서의 일반화 성능과 구분

## 5. 평가 지표 읽기

- 배치 정답률: 글자·공백·줄바꿈이 모두 맞은 문구 비율
- 문자 목록 F1: 위치를 무시했을 때 필요한 문자를 과다·누락 없이 만든 정도
- 문자·좌표 F1: 문자가 맞고 놓인 위치까지 맞은 정도
- 두 F1의 차이: 문자 보존과 위치 배치의 문제를 나누어 보는 단서
- 공백 제외 CER: 삽입·삭제·치환 수를 정답 문자 수로 나눈 값 · 반복 출력 때문에 100% 초과 가능
- 토큰 상한 도달: 최대 256개 생성으로 중단 · 반복 여부와 함께 원문 확인
- 소집단 비교: 음절 수·받침·모음 방향·단어 공백별 결과 · 표본이 작아 일반화 제한

## 6. 결론을 쓰는 기준

- C가 B보다 높음: 이번 조건에서 좌표 포함 보조학습에 유리한 관찰 · 단일 실행의 한계 명시
- C와 B가 같거나 C가 낮음: 제안 효과 미확인 · 반대 결과 포함 보고
- F1만 개선: 일부 문자·좌표 일치 개선 · 완성된 문구 생성 성공과 구분
- 모두 실패: 학습한 표본의 생성도 실패했는지 확인하여 오류 원인 좁히기
- 테스트 자료: 기존 결과를 이미 확인한 자료 재사용 · 탐색적 후속 분석으로 명시
- 한국어 의미 이해·OCR 성능 향상: 이번 실험만으로 입증 불가

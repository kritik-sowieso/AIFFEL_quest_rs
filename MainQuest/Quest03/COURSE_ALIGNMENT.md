# 수업 개념과 이번 실험의 연결

## 적용한 학습 흐름

사용자는 특정 LMS 노드의 과제를 그대로 재현하기보다, 딥러닝의 사전학습 기반 모델을 목적에 맞게 미세 조정하는 관례에서 연구를 출발시켰다. 과제 설명은 **HuggingFace 커스텀 프로젝트**의 흐름과 연결한다. 제공받지 않은 노드 원문이나 개별 루브릭을 인용하지 않는다.

| 배운 개념 | 이번 적용 | 확인 자료 |
|---|---|---|
| 기반 모델(backbone) | 고정 revision의 Qwen2.5-0.5B-Instruct | 모델 설정·실행 기록 |
| 토큰화(tokenization) | 한글·자모·공백·줄바꿈을 출력 토큰으로 학습 | 고정 입력 지시와 원시 생성 기록 |
| 미세 조정(fine-tuning) | 기반 가중치를 고정하고 LoRA 학습 | B/C 학습 코드·체크포인트 |
| 손실(loss)과 최적화 | 주 변환과 보조 과제의 평균 손실을 각각 0.5 반영 | 회차별 손실·업데이트 수 |
| 자료 분할과 일반화 | 학습 198 / 검증 25 / 테스트 25 | 고정 분할과 파일 지문 |
| 대조 실험 | 자모 목록과 자모·좌표 목록 비교 | 같은 원문·초기 모델·학습 횟수 |
| 모델 선택과 자료 누출 | 검증으로 먼저 고정한 뒤 테스트 평가 | frozen_selection.json |
| 모델 활용 | 선택한 실제 어댑터의 원시 출력을 임시 데모에 표시 | 데모 코드와 검수 기록 |

## 제출 안내의 요구와 연결

영문 소논문, 국제 학술지 형태의 LaTeX 양식, 동기·실험 조건표·결과 그림·결론을 준비한다. Overleaf용 소스와 PDF를 제공한다. 제출 위치는 사용자가 명시한 `MainQuest/Quest03`을 따른다.

저장소의 기존 동료 평가 체크리스트는 리뷰어가 확인할 공간으로 남겨 둔다. 모델 성능, 코드 완성도, 주석, 시행착오, 회고, 코드 구조에 대한 근거를 자료로 제공하되 체크 항목을 대신 승인하지 않는다.

## 이번 시행착오가 갖는 의미

독립 자모 이미지를 OCR로 읽어 좌표 주석을 얻으려던 계획은 파일럿에서 충분히 작동하지 않았다. 이를 숨기거나 합성 좌표를 OCR 결과라고 부르는 대신, 합성 좌표 보조학습의 효과라는 더 작은 질문으로 전환했다. 학습이 실행된다는 사실, 손실이 낮아지는 사실, 새로운 문구를 정확히 생성하는 사실도 구분한다.

이 문서는 실험의 개념적 연결과 기록을 설명한다. 작성자 개인의 느낀 점이나 아직 측정하지 않은 성공 경험을 대신 작성하지 않는다. 최종 회고에는 실제 결과와 함께 작성자가 느낀 점을 덧붙일 수 있다.

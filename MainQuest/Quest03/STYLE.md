# 고정 스타일 v0.1

2026-09-23 사용자가 선택한 **음절 윗줄 정렬** 방식이다. 계단식은 주 실험에서 사용하지 않는다.

- 입력: 완성형 한글과 공백, `. , ! ?`, 최대 24자. 파일럿 이후 확장 여부를 결정한다.
- 세로 모음(ㅏㅐㅑㅒㅓㅔㅕㅖㅣ): 초성 오른쪽. 받침은 초성 아래.
- 가로 모음(ㅗㅛㅜㅠㅡ): 초성 아래. 받침은 그 아래.
- 음절 사이 빈 셀 1개, 원문 단어 공백은 추가 빈 셀 2개.
- 된소리·겹받침은 ㄲ, ㅆ, ㄳ처럼 한 유니코드 자모로 유지한다.
- 복합 방향 모음(ㅘㅙㅚㅝㅞㅟㅢ)은 초기 범위에서 제외한다. 임의로 생략하지 않고 입력 오류를 알린다.
- 음절의 초성 행은 항상 0이다. 입력 문장 줄바꿈은 지원하지 않는다.
- 모델 출력은 줄 끝 공백과 바깥 빈 줄만 채점에서 무시한다. 내부 공백, 추가 설명, 코드 블록 표시는 오류다.
- 표시: 모든 문자와 공백을 동일한 폭의 셀로 그린다. 일반 브라우저 글꼴은 공백 폭과 한글 폭이 달라 정렬이 깨질 수 있다.

예시 (각 문자와 공백을 같은 폭으로 표시):

```text
ㄱㅏ ㅈㅣ ㅅ
ㅇ     ㅜ
```

위 예시의 원문은 `강지수`다. 출력 정답 제작 코드와 서비스 모델 추론은 분리한다.

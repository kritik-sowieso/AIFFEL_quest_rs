01

Embedding → 외부 decoder

연속 임베딩으로 마스크를 만든다. 픽셀 수준 목적함수가 언어 모델링에 간섭할 수 있다.

02

Next-token → 긴 마스크 시퀀스

마스크를 토큰으로 표현하지만, 촘촘한 출력을 순차 생성하면 시간이 늘어난다.

03

All-Mask → 대화와 분할의 생성 방식 분리

텍스트는 자기회귀적으로, 마스크 토큰은 한 번에 병렬로 예측한다.

논문 §I, Fig. 1–2, Table I · 모든 embedding 방식이 항상 대화 능력을 잃는다는 일반 법칙이 아니라, 논문의 문제 설정과 실험 관찰입니다.

왜 텍스트 토큰의 순차 생성 방식이 dense prediction과 충돌하는지 먼저 묻는다. 마스크 생성 단계 수와 실제 FLOPs·총 지연시간을 구분한다.

03 / MANIM EXPLAINER

텍스트는 한 토큰씩.
마스크는 모든 패치를 함께.

1

텍스트 생성 + <SEG>

이미지와 질문을 읽고 응답을 생성한다. <SEG>가 분할 단계의 시작을 알린다.

2

패치에 맞춘 [MASK] 준비

이미지 패치 특징·위치 정보를 마스크 임베딩에 결합하고, Phase 1의 KV cache를 재사용한다.

3

Hybrid attention

대화 영역은 causal, 마스크 영역은 bidirectional attention. 모든 패치 label을 한 번에 분류한다.

논문 §III-A, Fig. 2(c), Fig. 4 · <SEG>는 표준 vocabulary의 트리거이며, 외부 decoder로 넘기는 임베딩 자체가 아닙니다.

영상 재생 전 “무엇을 병렬화했을까?”를 묻는다. Phase 1의 텍스트 생성은 여전히 순차적이다. 마스크 패스 1회도 입력 크기에 따른 계산 비용을 가진다.

학습과 추론의 연결
학습은 GT ID mapping, 추론은 생성한 ID mapping을 사용한다. 대상 목록 생성은 기존 Ltext로 학습하며 별도의 ID 생성 loss를 추가하지 않는다.

 
논문 §III-C, Eqs. (1)–(8) · C는 배경 포함 head 용량. 위 label 표기는 one-hot supervision을 간단히 쓴 형태입니다.

 
원래 포스터 1페이지의 손실함수 부분을 요약했다. BCE와 CE의 차이는 예측 label 공간이고, Dice는 영역의 겹침을 보완한다. 모델의 모든 내부 구조가 DETR이나 SAM과 같다는 의미가 아니다.

O(1)의 범위

원본 그래프를 그대로 사용하며 중간 지점의 값을 추정하여 새 정량 데이터로 만들지 않았다. Fig. 9의 하드웨어는 H800, Fig. 8 및 Table X는 A800이다.
